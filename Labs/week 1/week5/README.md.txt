In **Task 1**, we worked with a 4×5 NumPy matrix representing sensor readings of four machines over five time intervals. First, we calculated the average reading for each machine using `np.mean()` with `axis=1`, which performs the operation row-wise. Then, we calculated the maximum value for each time interval using `np.max()` with `axis=0`, which works column-wise. After that, we normalized the matrix using broadcasting by dividing each value by the maximum value of its respective column. NumPy automatically adjusted the dimensions during this step without using loops, which demonstrates the power of broadcasting. We also used boolean indexing with `np.where()` to identify which machines had an average reading greater than 20. Finally, we reshaped the original 4×5 matrix into a 2×10 matrix using `reshape()`, making sure that the total number of elements (20) remained the same.

While solving Task 1, several challenges can occur. Many students confuse `axis=0` and `axis=1`, which leads to incorrect results. Broadcasting can also cause errors if dimensions do not match properly. Reshaping may raise errors if the new shape does not match the total number of elements. Another common issue is misunderstanding boolean indexing, since conditions return True/False arrays rather than actual values.

In **Task 2**, we created two 3×3 matrices with random integers using `np.random.randint()`. We performed matrix multiplication using the `@` operator, which multiplies rows of the first matrix with columns of the second matrix. Then we performed element-wise multiplication using the `*` operator, where corresponding elements are multiplied together. We extracted values greater than 100 from the matrix multiplication result using boolean masking. After that, we replaced all elements less than 10 in the original matrices with 0 using conditional indexing. Finally, we vertically stacked both matrices using `np.vstack()`, which combined them row-wise to form a 6×3 matrix.

The main challenges in Task 2 include confusing matrix multiplication (`@`) with element-wise multiplication (`*`), which produce completely different results. Another common issue is shape mismatch during matrix multiplication if the number of columns in the first matrix does not equal the number of rows in the second matrix. Students may also forget how boolean masking works when extracting values. Additionally, stacking requires both matrices to have the same number of columns; otherwise, it raises a dimension error.

Overall, these tasks helped in understanding axis operations, broadcasting, reshaping, boolean indexing, matrix operations, and handling NumPy dimension errors properly.
